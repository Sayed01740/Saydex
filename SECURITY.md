# Security Policy

Saydex Protocol prioritizes the security of its decentralized finance infrastructure and user assets.

## Non-Custodial Architecture

Saydex Protocol is an interface to decentralized smart contracts:
- The interface **never** has access to your private keys or seed phrases.
- The interface **never** holds custody of user assets.
- All transactions require explicit cryptographic confirmation from your connected Web3 wallet.
- All smart contract interactions route through audited, verified Uniswap V3 Core and Uniswap V4 Universal Router contracts.

## Supported Networks & Contract Safety

Users should always verify transaction parameters in their Web3 wallet before signing. Ensure that you are interacting with the official Saydex web application at:
- **Official Domain:** [https://www.saydex.site](https://www.saydex.site)

## Reporting a Vulnerability

If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly:

1. **Do not** open public GitHub issues for security vulnerabilities.
2. Email your findings with reproduction steps and potential impact to:
   - **Email:** `security@saydex.site`
3. We will acknowledge receipt of your vulnerability report within 48 hours and work with you to remediate the issue promptly.
